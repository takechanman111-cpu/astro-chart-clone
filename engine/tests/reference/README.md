# Independent comparison model

`astronomy.cjs` is an unmodified copy of Astronomy Engine 2.1.19 `astronomy.js` from the existing installed package (the filename extension alone was changed for this ESM project). Original author: Donald Cross, MIT license. Copyright and license text are preserved in the file header.

Source: https://github.com/cosinekitty/astronomy

Used only in tests to compare geocentric tropical apparent longitudes for seven bodies across four epochs. This is separate from the Swiss Ephemeris model. Agreement within the selected 60 arcsecond tolerance does not establish the validity of astrological interpretation.
